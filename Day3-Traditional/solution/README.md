# Lecture 3 答案说明

Day3 的核心是理解传统视觉管线。答案提供完整实现参考。

## 核心算法要点

### 1. 通道分离法
- 蓝色灯条: gray = B - R（蓝通道减红通道）
- 红色灯条: gray = R - B
- 也可以使用更复杂的加权: gray = B - 0.5*R - 0.5*G

### 2. 灯条筛选条件（参考 26_SP detector.cpp）
| 条件 | 典型值 | 意义 |
|------|--------|------|
| 长宽比 | > 3.0 | 灯条是细长的 |
| 面积 | > 20 px² | 过滤噪点 |
| 角度 | < 45° 或 ≈ 90° | 灯条接近竖直 |

### 3. 装甲板匹配条件
| 条件 | 典型范围 | 意义 |
|------|----------|------|
| 颜色一致 | is_blue 相同 | 左右灯条同色 |
| 间距/长度比 | 0.5 ~ 5.0 | 装甲板尺寸合理 |
| 角度差 | < 15° | 两灯条平行 |
| 正交性 | ±30° | 连线垂直于灯条方向 |

### 4. PCA 角点修正（26_SP traditional.cpp）
`lightbar_points_corrector()` 使用 PCA 分析灯条轮廓点，
找到主轴方向后重新计算四个角点，提高角点精度。

### 5. 数字分类器
LeNet 模型将装甲板数字区域归一化为 28×28 灰度图后分类。
`get_pattern()` 函数使用仿射变换提取并归一化 ROI。

### 6. Voter 投票机制
多帧投票确认装甲板的 color/name/type，降低单帧误识别率。
每帧对检测结果投票，达到 threshold 票数后锁定结果。

请对照 26_SP 源码阅读以上要点。
